# Click Indicator + Showcase — GD 2.2074 Android

This is the source project for the requested Geode mod.

It includes:
- cyan click indicator inspired by the supplied screenshot
- pause menu Click ON/OFF toggle
- pause menu Showcase button
- pre-programmed showcase input sequence (no recording)

A compiled `.geode` binary is not included because compiling Android Geode mods requires the Geode SDK/Android NDK toolchain. The included GitHub Actions workflow can build an Android64 `.geode` package automatically after the project is uploaded to a GitHub repository.
